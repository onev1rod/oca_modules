# OCA Modules for Odoo 18.0

This repository contains custom and community modules for **Odoo 18.0**, primarily sourced from the OCA (Odoo Community Association) and other open-source developers.  
These modules extend the functionality of Odoo, adding features for document management, payroll, UI customization, and more.
